# GAZE ECONOMY — Project Files

Data visualisation / interactive experience exploring how internet culture
codifies reality into visual reflex. Theoretical anchors: McLuhan + Baudrillard.
Case study: COVID-19 lockdown (2020–2021) as the moment the internet became
the only window to reality.

---

## Folder Structure

```
gaze-economy/
├── research/
│   └── perplexity-deep-research.md   ← Full Perplexity research brief + findings
├── data/
│   ├── keywords.json                 ← Master keyword set (4 phases, sourced from research)
│   ├── giphy_results.json            ← Raw Giphy API output (generated by script 01)
│   ├── dataset.json                  ← Processed, normalised dataset (generated by script 02)
│   └── summary.csv                   ← Flat CSV for spreadsheet inspection
├── scripts/
│   ├── 01_giphy_probe.py             ← Queries Giphy API for each keyword
│   └── 02_process_results.py        ← Normalises + structures results
└── assets/                           ← Game assets, backgrounds, sprites (TBD)
```

## Setup (run in VS Code terminal / Claude Code)

```bash
# Install dependencies
pip install requests python-dotenv

# Create .env file with your Giphy API key
echo "GIPHY_API_KEY=your_key_here" > .env

# Get a free Giphy API key at:
# https://developers.giphy.com/
# Developer account → Create App → SDK type → free tier
# Rate limit: 100 requests/hour (we have ~55 keywords, well within limit)
```

---

## Run Order

```bash
# Step 1: Query Giphy for all keywords (~60 seconds, ~55 API calls)
python scripts/01_giphy_probe.py

# Step 2: Normalise and process results
python scripts/02_process_results.py

# Output: data/dataset.json is ready for the game/vis to consume
```

## Key Research Findings (for narrative design)

- **Giphy usage rose 65% Feb→Apr 2020** (Adweek reporting Giphy internal data)
- **COVID meme interest correlated with death counts** r=0.640 (Skórka et al. 2022)
- **Passive scrolling → 9% daily wellbeing drop** (Verduyn et al. passive Facebook study)
- **Doomscrolling coined ~2018, peaked 2020** (UF study 2022)
- **Digital communication cannot substitute face-to-face** (Stieger et al. Nature 2023)
- **Memes are "mirrors AND molders"** of societal narratives (meme semiotics research)
- **TikTok scrolling framed as self-care** but also a soft cage (Abidin et al. 2023)
